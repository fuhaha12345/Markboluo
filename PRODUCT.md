# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: Astro static site, deployed through GitHub Pages for a lightweight, version-controlled blog shell.

## Users

The primary user is the blog owner, who needs a calm public home for future AI learning notes, experiments, and projects. Visitors should be able to understand the site's purpose and find its future sections without needing any content to be published yet.

## Product Purpose

Provide a personal, maintainable home for AI learning in progress. The first release is deliberately an empty content shell: it establishes navigation, identity, and future publishing surfaces without inventing notes, projects, or personal biography.

## Positioning

An honest work-in-progress space for AI learning, where the structure is ready before the archive is filled.

## Operating Context

The site is maintained in a GitHub repository and published as a static site with GitHub Pages. Future content should be added as versioned Markdown or MDX files.

## Capabilities and Constraints

- The initial release includes a responsive home page and empty About, Projects, and Notes routes.
- No article, project, testimonial, or biographical content should be fabricated.
- The site must work without a database, authentication, or server-side runtime.
- The repository is `fuhaha12345/Markboluo` and the Pages base path is `/Markboluo`.

## Evidence on Hand

The repository currently contains only the original README and LICENSE. No authored content or brand assets were supplied.

## Product Principles

- Structure before volume.
- Every future entry should be easy to version and revise.
- Empty states should be intentional, not disguised as unfinished content.
- Keep the publishing system small enough to maintain.
